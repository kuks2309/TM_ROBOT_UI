# profiles/ — 로봇별 티칭·레시피 데이터

두 기계가 실제로 갈리는 것은 **코드가 아니라 데이터**다. 팔레트 자세·랜드마크
좌표·레시피는 기계마다 달라야 하고, 통합해도 그건 남는다.

| | 파일 | 출처 |
|---|---|---|
| `mk4/` | MK4 티칭·레시피 | `tm-robot-4.zip` (로봇 원본, sha256 검증본) |
| `mk2/` | — | 지금은 패키지 안(`src/TM_Robot_Task_Manager/data`·`config/recipes`)에 그대로 있다 |

## ⚠️ 아직 배선되지 않았다

`paths.py` 는 여전히 패키지 안의 `data/`·`config/recipes/` 를 본다.
이 디렉터리는 **MK4 데이터를 잃지 않게 한 벌에 담아둔 것**이고,
프로필별 경로 전환(`PROFILE_DATA_DIR`·`PROFILE_RECIPES_DIR`)은 다음 단계다.

전환하기 전에는 이 워크스페이스를 MK4 에 그대로 올리면 **MK2 의 티칭값이 보인다.**
MK4 에 배포할 때는 이 폴더 내용을 패키지 안으로 덮어쓰거나, 경로 전환을 먼저 끝내야 한다.
