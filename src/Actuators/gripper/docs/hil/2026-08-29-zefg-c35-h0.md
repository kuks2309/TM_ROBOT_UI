## 영점 매핑 실측 (2026-08-29 00:50-00:55) — ★ 이식 필수 정보

**이 개체는 표시 0mm = 실물 완전 열림, 표시 35mm = 실물 완전 닫힘이다** (사용자 실물 목시 확인 ✓, init_direction 0x0082=0(open calibration)·io_mode 0x0090=0 상태).

- 발견 경위: "표시 35mm 열림" 상태를 사용자가 "전혀 안 열렸다"로 반박 → 상태 레지스터가 Clamping→Dropping(빈 파지·낙하 감지, 정지 전류 −0.38A) — 조가 맞물려 눌린 상태의 신호 → 0mm 명령으로 실물 열림 확인.
- [Z-EFG-C35 Product Manual V20240120, page 6](../../../../../references/hitbot/z-efg-c35/Z-EFG-C35%20Brochure_V20240120.pdf) 의 "Close the gripper (set the clamping position to 0mm)" 예제와 **반대** ⚠ — 매뉴얼 예제의 전제(캘리브레이션 설정)가 명시돼 있지 않으므로 본 실측을 정본으로 삼고, 설정 변경(0x0082) 시 재실측한다.
