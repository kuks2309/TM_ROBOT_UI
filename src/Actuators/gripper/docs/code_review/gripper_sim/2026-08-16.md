# gripper_sim 인벤토리 (M3 신규 — coding SOP §2 계획 단계 표)

> **대상**: `Actuators/gripper/gripper_sim/` — LECP6 병렬 I/O 플랜트 모형 + SIL 하니스.
> **ROS-free · 스테이션 접근 0** — 포트 3종을 구현해 `gripper_motion` FSM 을 태운다.
> **왜 필요한가**: M2 시험은 페이크 포트에 신호를 손으로 주입한다. 플랜트가 없으면
> «명령 → 물리 응답 → 피드백» 폐루프가 재현되지 않아, 실기에서만 드러나는 순서 결함을 못 잡는다.
> **모형의 근거는 실기 실측**이다(`docs/hil/2026-08-13-open-close-cycle.md` §4·§5).

## 3라운드 — 플랜트 충실도 정정 (debt-093 상환)

M4 ROS 폐루프에서 **grip 경로를 돌릴 수 없다**는 것이 드러났다: 플랜트가 매거진 감지를
«파지 성립» 으로 모형화해, grip 은 2점 감지를 요구(`require_both`)하는데 감지는 grip 이 끝나야
서는 순환이 생겼다(실측: `magazine_present=true` 인데 DI[24]=DI[25]=1=미감지).

실측 기록이 모형을 반증한다 — HIL §5-5 는 «매거진 **안착** 시 2점이 40ms 차로 함께 감지되고,
제거 시 같은 프레임에 함께 해제» 라고 적고 있다. 2점은 근접센서(OMRON E2E-X9C212)이며
**실물의 존재**를 본다. 감지를 `magazine_present_` 기준으로 고쳤다.

| 원점복귀가 매거진 존재를 지움 | **등가 뮤턴트** — 아래 |

마지막은 시험 공백이 아니라 **도달 불가**다. `validate()` 가 home 인터록을 `forbid_any` 로
고정하고(`fsm_types.cpp:111`) 런타임 게이트가 `SETUP` 인가 직전과 행정 중에 3곳에서 막으므로
(`gripper_fsm.cpp:175·506·536`), 매거진이 있는 채로 원점복귀가 실행될 수 없다. 억지 시험을
만들지 않고 이 사실을 기록한다.
