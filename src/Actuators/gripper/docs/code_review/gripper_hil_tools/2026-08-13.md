# gripper HIL 시험 도구 인벤토리 (coding SOP §2 — 신규 설계표)

> **대상**: `Actuators/gripper/tools/gripper_hil_cycle.py` — 실기 그리퍼 개폐 반복 시험기.
> **스테이션 직접 접근 없음** — `remote_io_ros` 의 `io_service`(쓰기)·`io_resp`(20ms 관측)만 쓴다(ADR-008 Q7).
> **왜 만드는가**: 읽기 전용 프로브의 초 단위 폴링으로는 `BUSY` 상승·하강 구간을 한 번도 포착하지 못했다
> (2026-08-13 1차 실기 시험). 20ms 스트림을 구독해야 동작 타이밍이 관측된다.
> **운영 코드 아님** — `gripper_motion`(M2 FSM)의 전이표가 서면 이 도구는 그 시퀀스로 대체된다.

## 안전 규율 (본 도구가 지키는 것)

- **모든 경로에서 복귀** — 정상·오류·예외·중단 모두 `finally` 가 `DRIVE`·`IN0~5` 를 0 으로 되돌린다.
- **알람·비상정지 감지 시 즉시 중단** — `alarm_ok`(ALARM=1 且 ESTOP=1, negative-true) 가 깨지면 사이클 정지.
- **echo 대조** — 서비스 응답의 인덱스·레벨이 요청과 다르면 실패로 처리(응답 신뢰 금지).
- **워치독 미구성 전제** — 재적용 경로가 비활성인 상태에서만 쓴다(`debt-077` 미해결).

## 미포함 (경계)

- 시퀀스 정책(전이표·인터록) — M2 `gripper_motion` 소관. 본 도구는 파리티 관측용 단발 실행기.
- 스테이션 물리 접근 — `remote_io_ros` 소유.
