# gripper_hal/impl/remote_io 인벤토리 (M1 신규 — coding SOP §2 계획 단계 표)

> **대상**: `Actuators/gripper/gripper_hal/impl/` — `remote_io_ros` 노드의 IO 서비스를 통해 M0 포트 3종을 구현한다.
> **자체 Modbus 금지** — 스테이션 유일 쓰기 마스터는 `remote_io_ros`(ADR-008 Q7, ADR-001(remote_io)).
> 본 계층은 **rclcpp 를 포함하지 않는다** — ROS 결선은 `IStationIoClient` 구현으로 조립층(M4)이 주입한다.
> **게이트(M1)**: 단위 PASS · `⟦CI:gripper-io-single-master⟧`.
