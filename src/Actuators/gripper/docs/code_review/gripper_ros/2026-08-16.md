# gripper_ros 인벤토리 (M4 — coding SOP §2 계획 표 → §6 구현 후 실측 갱신)

> **대상**: `Actuators/gripper/gripper_ros/` — M0~M3 코어를 ROS 2 에 결선하는 **조립층**.
> 결정 근거: [ADR-001-gripper-ros-assembly](../../adr/ADR-001-gripper-ros-assembly.md)
> **자체 Modbus 금지** — 스테이션 접근은 `io_service`/`io_resp` 뿐(ADR-008 Q7, `⟦CI:gripper-io-single-master⟧`).
> **판정 로직은 rclcpp 밖**(ADR-001 D3) — `config_loader`·`result_map` 은 plain CMake 로 단위 시험한다.

## ROS 계약 (공개 표면)

| 이름 | 타입 | 방향 | 비고 |
|------|------|------|------|
| `~/command` | `gripper_ros/action/GripperCommand` | action server | 장치 계층의 유일한 외부 구동 표면 |
| `io_service` | `tc_msgs/srv/Io` | client | `remote_io_ros` 소유. 쓰기는 전부 여기로 |
| `io_resp` | `tc_msgs/msg/Io` | sub | 20ms 입력 이미지 |

비트 인덱스 = 워드×16 + 비트(LSB-first) — `IStationIoClient` 와 `remote_io_ros` 가 같은 규약이라 변환 없음.

| **SIL 폐루프** | 스테이션(플랜트) + 노드로 냉시동 release **완주** — 궤적 `PRECHECK → ORIGINATING → WAIT_SETON → STEP_SET → DRIVING → VERIFY → DONE`, `result_code=0` |
| 인터록 | 매거진 미감지 grip **거절**(`InterlockRejected`) 폐루프 실측 |

구현 중 잡은 결함 2건:

- **알람 그룹 비트 대응을 추측으로 썼다가 legacy 원문이 뒤집었다.** 실제는 B=0x2·C=0x4·D=0x8·**E=0x0**
  (amr04 `gripper_node.cpp:1115-1141`). E 가 전 비트 0 이라 «0 = 알람 없음» 이 성립하지 않아
  알람 활성 여부를 함께 받는 형태로 고쳤다. 추측판을 되돌리면 red 6건.
- **정상 완료 경로가 `PHASE_ABORTING` 으로 표시됐다.** `kReleasingOutputs` 는 정상 시퀀스의 마지막
  단계인데 «안전 정지» 로 매핑돼, 성공한 동작이 관측자에게 중단으로 읽혔다. SIL 폐루프 출력을
  눈으로 보고 발견했다 — 시험은 통과하고 있었다.

## 잔여

- **grip 완주는 SIL 로 시험할 수 없다**(debt-093) — 플랜트가 매거진 감지를 «파지 성립» 으로 모형화해
  실측(존재 감지)과 어긋난다. grip 은 2점 감지를 요구하는데 감지는 grip 이 끝나야 서는 순환이 생긴다.
- `COMMAND_STEP` 미수락(debt-094) — 키스위치 입력이 신호맵에 없다.
- HIL — 실기 검증은 리모트 `~/LGIT_C6_MoMa` 에서 별도 수행.
