# M3 플랜트 충실도 정정 — 매거진 감지는 «안착» 이다 (2026-08-16, debt-093 상환)

## 무엇이 틀렸나

플랜트가 매거진 감지를 **파지 성립**(`magazine_held_`)으로 모형화했다. 실기 2점은 근접센서
(OMRON E2E-X9C212)이며 **실물의 존재**를 본다.

실측 기록이 이미 그렇게 적고 있었다 — HIL 개폐 시험 §5-5:
«매거진 안착 시 2점이 40ms 차로 함께 감지되고, 제거 시 같은 프레임에 함께 해제된다».

## 어떻게 드러났나

M4 ROS 폐루프에서 grip 을 돌리려다 막혔다. grip 인터록은 2점 감지를 요구(`require_both`)하는데
감지는 grip 이 끝나야 서므로 **순환**이 생긴다. 실측: `magazine_present=true` 인데
DI[24]=DI[25]=1(미감지).

SIL 단위 시험은 이 순환을 우회하고 있었다 — S4·S5·S8 이 플랜트를 직접 구동해 강제로 닫은 뒤
감지를 만들었다. 그래서 «시험은 전부 통과하는데 실제 경로는 못 돈다» 상태였다.

## 고친 것

- `magazineDetected()` 를 `magazine_present_` 기준으로. 2점 독립은 유지(`sensor_2_enabled_`).
- S4 를 «놓으면 감지된다 → grip 완주» 로 재작성. 완주는 감지가 아니라 **위치**(`position()`)로
  단언한다 — 감지 기준이 바뀌었으니 완주 판정이 감지에 겹치면 시험이 겉돈다.
- S5 에 **명시적 `kOrigin` 거절**을 추가. 최대 행정이라 낙하 위험이 profile home 과 같다.
- S8 에서 플랜트 강제 구동 제거 — 안착만으로 1점 정렬을 재현한다.

## 검증

| 항목 | 결과 |
|---|---|
| 빌드 | 경고 0 |
| SIL | S1~S8 전부 통과 |
| **뮤테이션** | 3종 사망(red 10·4·10) · **등가 1종** |
| **ROS 폐루프** | release → 안착(DI 0) → **grip 완주** → home 거절 → 원점복귀 거절 → 회수 후 release·home 완주 |

등가 뮤턴트는 «원점복귀가 매거진 존재를 지운다» 이다. 시험 공백이 아니라 **도달 불가**다 —
`validate()` 가 home 인터록을 `forbid_any` 로 고정하고(`fsm_types.cpp:111`) 런타임 게이트가
`SETUP` 인가 직전·행정 중 3곳에서 막는다(`gripper_fsm.cpp:175·506·536`). 억지 시험을 만들지
않고 사실을 기록한다.

## 남는 성질 (결함 아님)

grip 완료 판정은 «매거진이 거기 있다» 를 보는 것이지 «물었다» 를 보는 것이 아니다. 이는 설비의
성질이다 — 무부하에서 `INP` 가 서지 않는 실측(P3) 때문에 R2 가 완료 근거를 매거진 감지로 잡았고,
그 감지가 근접센서다. 우리 모형은 이제 그 한계까지 충실히 재현한다.
