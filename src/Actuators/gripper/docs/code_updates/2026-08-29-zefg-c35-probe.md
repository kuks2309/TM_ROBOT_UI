# 2026-08-29 — HITBOT Z-EFG-C35 H0 프로브 신설 (zefg_c35_probe.py)

- **무엇**: `tools/zefg_c35_probe.py` 신규 — RS485 Modbus RTU 읽기 전용(H0) 프로브. 초기화·파지 상태, 위치·속도·전류 피드백, ID·baud 판독. `--selftest` 는 매뉴얼 예제 프레임 6종(CRC 포함)과 비트 대조.
- **왜**: ADR(Architecture Decision Record)-005 로 확정된 Z-EFG-C35 신규 장착(신규 호기, RTU 제어)의 실기 통신 검증 첫 단계. 그리퍼 HIL 규율 H0(관측·읽기 전용)를 지키기 위해 쓰기 FC(0x06/0x10)는 selftest 조립 전용으로 격리하고 송신 경로를 두지 않았다.
- **검증**: selftest 6/6 OK (로컬 + nx-orin-1 원격). 실기 H0 는 물리 계층 이슈(전 보레이트에서 0x00 1바이트 수신 — A/B 극성 반전 의심)로 보류, 배선 확인 후 재시도 예정.
- **함수표**: `tools/docs/function_table.md` (모듈 로컬 원본, 동반 신설). 루트 집계(functions-index) 반영은 재배치(ADR-005 단계①②) 완료 시 일괄 — 타 세션 파일 점유로 대기 중.
- **근거 문서**: [ADR-005](../adr/ADR-005-multi-vendor-restructure.md) · [Z-EFG-C35 Product Manual V20240120, page 4-8](../../../../../references/hitbot/z-efg-c35/Z-EFG-C35%20Brochure_V20240120.pdf)
- **추가 (2026-08-29)**: `checks/gripper-io-single-master.sh` 의 소스 스캔에서 `tools/` 제외 — 본 프로브의 modbus 심볼이 게이트에 걸린 것을 ADR-005 D4(별개 RS485 버스, 스테이션 보호 무관) 부분 적용으로 해소. Crevis 스테이션 보호(빌드 그래프·hal impl 스캔)는 불변. 게이트 재실행 ✅(39파일).
