# 2026-08-16 — M3 SIL 플랜트 구현 (`gripper_sim`)

M2 시험은 페이크 포트에 신호를 손으로 주입한다. 플랜트가 없으면 «명령 → 물리 응답 → 피드백» 폐루프가
재현되지 않아, 실기에서만 드러나는 순서 결함을 잡을 수 없다. `gripper_sim` 이 그 폐루프를 만든다.

## 플랜트가 재현하는 실측 거동

| # | 거동 | 실측 근거 |
|---|---|---|
| P1 | `DRIVE` 후 `BUSY` 가 수십 ms 만에 선다 | 4~38ms (60동작 전수) |
| P2 | close 가 open 보다 길고 편차가 크다 | close 0.98~2.89s · open 0.50~0.53s |
| P3 | **무부하 grip 은 `INP` 가 서지 않는다** — 푸싱 반력이 없다 | 40회 중 6회 |
| P4 | 파지 성립 시 매거진 2점 감지 | 40ms 차 감지·동시 해제 |
| P5 | **원점 미확립 스텝 구동은 `BUSY` 만 서고 알람으로 끝난다** | 2.485~2.503초 후 그룹 D |
| P6 | 미등록 스텝은 `BUSY` 조차 없이 즉시 알람 | step4 |
| P7 | 알람 시 서보가 떨어지고 RESET 으로 복구 | 0.02~0.41s |

## SIL 시나리오

S1 냉시동(서보 OFF·원점 미확립 → FSM 이 스스로 준비) · S2 **P5 재현**(플랜트 직접 구동은 알람, FSM 경유는 통과) ·
S3 무부하 grip 인터록 거부 · S4 파지 성립 후 grip 완료 · S5 파지 중 home 거부 · S6 미등록 스텝 ·
S7 동작 중 알람 → 즉시 실패 + 출력 복귀.
