## debt-023 상환 대상 결함

| 항목 | 내용 |
|---|---|
| 현상 | `recvRequest` 의 `::recv` 에 상한이 없어, 핸들러가 기대한 요청 수(`serveBank(fd, n, …)` 의 n)보다 클라이언트가 적게 보내면 **영구 대기 → `join()` hang → CI 타임아웃**(clean-fail 아님) |
| 조건 | 구현 변경으로 클라이언트 요청 수가 줄면 발생. 현재 전 테스트는 카운트 정합이라 통과 중 |
| 처방 | 수락 fd 에 `SO_RCVTIMEO` 부여 → 타임아웃 시 `recvRequest` 가 빈 벡터 반환 → `serveBank` 는 이미 `req.size() < 12` 에서 return 하므로 클린 종료 |
| 회귀 | 카운트 불일치 케이스 1종 — 핸들러는 n건을 기대하고 클라이언트는 1건만 보낸 뒤 대기, `join()` 이 상한 내 반환하는지 검증 |
