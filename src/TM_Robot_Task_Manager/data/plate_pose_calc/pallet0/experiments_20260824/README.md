## 015421 이 오염인 이유

`pallet0_cali-2.yaml` 은 `move_to_point` 의 Rz 만 -90 → 180 으로 바꾸고
`move_linear` 의 오프셋을 그대로 뒀습니다. `Move_Line("TPP", ...)` 는 공구좌표
상대이동이라 경로 전체가 함께 회전합니다. 계산 결과 **원래 스캔 지점과 최대 250mm**
어긋난 곳을 찍었고, 그 결과 jig 배정이 뒤바뀌어 W×H 가 137x197 → 197x137 로
뒤집혔습니다. 같은 마커를 다른 각도에서 본 것이 아니므로 회전 실험 자료로 쓸 수 없습니다.
