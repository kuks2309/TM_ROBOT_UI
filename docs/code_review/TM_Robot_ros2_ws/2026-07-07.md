## Core 인벤토리

### 1. 목적

TM(Techman) 협동로봇(TM5/TM12/TM14 계열)을 ROS2 Humble 기반으로 제어하는 통합 워크스페이스다. 원 목적은 AR 태그 기반 팔레트 픽업(`src/TM_Robot_Task_Manager/package.xml:5` "TM Robot Task Manager with Qt5 GUI for AR tag based pallet pickup")이며, 실제 코드는 레시피(Job 시퀀스) 편집·실행, TM Landmark/AR 태그/AI 검출 비전, 카메라 캘리브레이션, 핸드아이·정밀도 테스트, IO 제어, PS2 조이스틱 조그, 좌표계(TF) 관리를 포함하는 오퍼레이터 콘솔로 확장되어 있다.

로봇과의 실제 통신은 Techman 공식 드라이버 `tm_driver`(서드파티, C++)가 담당한다: 로봇 제어박스(TMflow, Windows 기반)에 TCP 2소켓 — SCT(Listen node, 포트 5890, `tm_driver/src/tm_sct_communication.cpp:17`)로 스크립트 송신, SVR(Ethernet Slave, 포트 5891, `tm_driver/src/tm_svr_communication.cpp:17`)로 상태 수신 — 로 접속하고, 이를 ROS2 토픽/서비스로 노출한다. first-party 코드는 전부 이 드라이버의 토픽/서비스 위에서 동작하며 로봇과 직접 소켓을 열지 않는다(예외: `scripts/tm_camera_bridge.py`가 TMflow 비전의 HTTP 푸시를 포트 6189로 수신).
