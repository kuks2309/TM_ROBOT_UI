## 1. 개요
사용자 요구 = "MoveIt 없이 point 이동으로 엔드이펙터를 옮길 때 든 자세를 최대한 유지, Z 먼저 또는 회전 최후". 인수인계 문서(worklog 5건·code_review·issues_and_fixes·ADR/계획서) 및 모션 코드 조사 → **자세 변동의 원인 2가지를 분리 규명** → 신규 Job 1종 구현·무동작 검증 완료. **실로봇 기동·실모션은 미수행**(사용자 결정: 구현 먼저).

## 2. 원인 분석 (규명)

| # | 원인 | 근거 |
|---|---|---|
| A | **PTP(Point To Point) 보간** — `move_to_point`(PTP_T)는 목표만 직교좌표, 보간은 관절공간 → 시작·끝 자세가 같아도 **경로 중간에 TCP(Tool Center Point) 자세가 휜다** | `PTP("CPP",…)` 생성: [tm_command.cpp:55-67](../../src/Robot/tmrobot_official_packages/tm_driver/src/tm_command.cpp) |
| B | **목표 자세가 현재와 다름** — 두 이동 Job 모두 파라미터 Rx/Ry/Rz 를 그대로 목표로 전송 → 병진·회전이 섞여 동시 진행 | [job_executor.py:590-598](../../src/TM_Robot_Task_Manager/tm_task_manager/job_executor.py), [:771-777](../../src/TM_Robot_Task_Manager/tm_task_manager/job_executor.py) |
| 참고 | LINE_T 는 `Line("CAP", x,y,z,rx,ry,rz, vel_mm/s, acc_ms, blend, fine)` = 직교 직선 보간 → 양 끝 자세가 같으면 경로 전체 자세 변화 원리상 0 | [tm_command.cpp:68-81](../../src/Robot/tmrobot_official_packages/tm_driver/src/tm_command.cpp) |

⇒ 자세 유지 = **LINE_T + 목표 자세를 현재값으로 고정**. 사용자가 말한 "Z 먼저 / 회전 최후"는 자세 유지 자체가 아니라 **경로 형상·회전 분리** 정책 → 두 메커니즘을 분리 설계.

## 3. 결정 (사용자 선택, ADR 기록)
- 축 순서: **적응형(안전순)** — 상승 = Z 먼저 → XY / 하강 = XY 먼저 → Z 하강
- 회전: **현재 자세 완전 고정**(회전 명령 없음 → "회전 최후"는 회전 구간 부재로 자동 충족)
- 범위: **신규 Job + PyQt/웹 브리지 양쪽 등록** (기존 Job 무수정)
- 순서: 구현 먼저, 로봇 기동·실기 검증은 후속
- ADR: [docs/adr/2026-07-27-pose-keep-move.md](../adr/2026-07-27-pose-keep-move.md)
