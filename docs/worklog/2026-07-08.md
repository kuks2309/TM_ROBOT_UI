## 3. 사고 요약 및 교훈
- **원인**: 로봇 라이브 상태 미재확인(stale node list) 후 자동 curl 검증으로 실모션 전송. 과속 회전이 협동 안전한계 초과 → 안전정지 → 이후 J5 모터 hold 보호 latch.
- **복구**: 전원 완전 차단 5분(방전) → 재부팅 정상. 짧은 재부팅으로는 안 풀리는 하드웨어 보호 latch였음. 하드웨어 손상 없음.
- **재발 방지(적용됨)**: 코드 안전 하드닝(게이트·clamp) + 메모리 규칙 [[robot-live-before-motion]](라이브 로봇 자동 검증 금지, 실모션은 입회·저속·소량). 저속 재검증은 사용자 입회 하 GUI 클릭으로만 수행.
